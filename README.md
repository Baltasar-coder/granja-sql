# Granja SQL

Juego educativo para aprender SQL de cero a experto gestionando una granja.
47 misiones: SELECT, INSERT/UPDATE/DELETE, agregados, JOIN, subconsultas, CTE, window functions,
vistas, indices, transacciones y triggers. Funciona en el navegador (SQLite via sql.js), sin instalar nada.

El progreso se guarda en el propio navegador de cada persona.
